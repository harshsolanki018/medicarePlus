# MediCare Plus 

A full-stack healthcare appointment management system built using React.js, Node.js, Express.js, and MongoDB. The platform enables patients to book appointments with doctors online while providing administrators with complete control over doctor, patient, and appointment management.

---

## Overview

MediCare Plus is a web-based healthcare management platform designed to streamline the appointment booking process between patients and doctors. Patients can register, browse available doctors, schedule appointments, and track appointment status. Administrators can manage doctors, patients, and appointments through a dedicated dashboard.

---

## Features

### Patient Features

- User Registration & Login
- Browse Available Doctors
- View Doctor Details
- Book Appointments Online
- Track Appointment Status
- View Appointment History
- Responsive User Interface

### Admin Features

- Secure Admin Login
- Manage Doctors (Add, Edit, Delete)
- View Registered Patients
- Manage Appointment Requests
- Update Appointment Status
  - Pending
  - Approved
  - Completed
  - Cancelled
- Dashboard for System Management
